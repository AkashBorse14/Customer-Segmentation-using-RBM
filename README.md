# Customer Segmentation using RBM

## Project Overview

This project focuses on customer segmentation using a deep learning approach based on Restricted Boltzmann Machines (RBM).

The goal is to group customers into different segments based on their purchasing behavior, enabling businesses to better understand customer patterns and improve marketing strategies.

## Dataset

* Dataset contains customer transaction / behavior data
* Features may include:

  * Customer ID
  * Purchase history
  * Product interactions
  * Behavioral patterns


## Technologies Used

* Python
* NumPy, Pandas
* Matplotlib / Seaborn
* Scikit-learn
* PyTorch / TensorFlow (RBM implementation)


## Model Used

* Restricted Boltzmann Machine (RBM)
* Unsupervised Learning technique
* Used for feature learning and clustering


## Workflow

1. Data preprocessing and cleaning
2. Data transformation (normalization / encoding)
3. RBM model building
4. Training the model
5. Extracting hidden features
6. Customer segmentation / clustering
7. Visualization of segments


## Output

* Customers are grouped into different segments
* Each segment represents similar purchasing behavior
* Helps in targeted marketing and business decisions


## How to Run

1. Open the notebook in Google Colab or Jupyter Notebook
2. Install required libraries
3. Run all cells step by step
4. Analyze the segmentation results


## Applications

* Targeted marketing
* Customer retention strategies
* Recommendation systems
* Business analytics
